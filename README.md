# Sonia Samani Portfolio

This is my final portfolio project for Code the Dream Intro to Programming.

## Features

- About and Experience sections
- Skills added with JavaScript
- GitHub projects loaded using the GitHub API
- Leave a Message form
- Weather App using the Open-Meteo API

## How to View

Open `index.html` in a web browser to view the portfolio.

From the portfolio navigation, click **Weather App** to open the Open API project.

## Technologies Used 

- HTML
- CSS
- JavaScript
- GitHub API
- Open-Meteo API
